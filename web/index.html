Test page: the 64/128/256-byte face codecs running locally with int8 weights. Photos never leave your device.

Each result is shown next to the smallest AVIF image that is at least as many bytes. Only the AVIF's compressed frame data is counted: the rest of the file (about 280 bytes) is identical for every face, so the decoder keeps it as a template, the same way the Face24 decoder keeps its codebook.
